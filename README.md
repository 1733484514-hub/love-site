# 情侣恋爱网站

本项目是一个可直接打开的静态情侣恋爱网站，按照《情侣恋爱网站产品需求文档_音乐播放器重点版.docx》实现了第一版 MVP。

## 打开方式

推荐打开方式：

`http://127.0.0.1:4173/`

也可以直接用浏览器打开：

`index.html`

默认进入暗号：

`20260311`

## 已包含功能

- 私密暗号入口
- 首页恋爱天数与纪念日倒计时
- 全局音乐播放器
- 情侣专属歌单、歌词高亮、迷你播放器
- 回忆时间线
- 情侣相册与大图预览
- 情话留言板，本地保存
- 愿望清单，本地保存
- 约会计划与每日心情记录

## 替换素材

- 主视觉：`assets/hero-couple-music.png`
- 相册图：`assets/gallery-*.png`
- 歌曲封面：`assets/cover-*.png`
- 音频文件：`music/*.wav`

如果要替换歌曲，请同步修改 `app.js` 里的 `tracks` 数组。

当前歌单显示为：

- 莫文蔚《真的吗》
- 汤令山《用背脊唱情歌》

说明：莫文蔚《真的吗》已接入你提供的本地授权文件 `music/mo-wen-wei-zhen-de-ma.mp3`；Gareth.T / 汤令山《用背脊唱情歌》已接入 `music/gareth-t-yong-bei-ji-chang-qing-ge.mp3`。
